# DataScope 📊

**A streamlined data analysis and visualization tool built with Python and Streamlit.**

DataScope is an interactive web application designed to make data exploration effortless. Upload your dataset, visualize trends, calculate statistics, and clean your data—all within a user-friendly interface.

---

## 🚀 Features

* **📂 Easy Data Upload:** Drag-and-drop support for CSV and Excel files.
* **📈 Interactive Visualization:** Instantly generate Line charts, Bar charts, and Scatter plots for any columns.
* **🧮 Statistical Analysis:** Get descriptive statistics (mean, count, std dev, etc.) for selected numeric columns.
* **🛠 Data Operations:** Modify your dataset on the fly by dropping unwanted columns.
* **📱 Responsive Sidebar:** Navigate easily between Home, Visualization, Analysis, and Operations modes.

---

## 🛠️ Installation

Follow these steps to set up the project locally.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/candelatesla/DataAnalyzer.git](https://github.com/candelatesla/DataAnalyzer.git)
    cd DataAnalyzer
    ```

2.  **Install dependencies:**
    Make sure you have Python installed, then run:
    ```bash
    pip install streamlit pandas
    ```

---

## 🏃‍♂️ Usage

1.  **Run the Streamlit application:**
    ```bash
    streamlit run dwm.py
    ```

2.  **Open the App:**
    A new tab will open in your default browser (usually at `http://localhost:8501`).

3.  **Start Analyzing:**
    * **Upload your CSV:** Click "Browse files" to upload your dataset.
    * **Explore:** Use the sidebar to switch between:
        * *Data Visualization:* To plot graphs.
        * *Data Analysis:* To view summary statistics.
        * *Data Operations:* To remove columns.
